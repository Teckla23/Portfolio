# My Portfolio

A minimalist, multi-page scrolling landscape presentation portfolio tracking professional milestones, education backgrounds, and technical credentials. Styled utilizing an external Bootstrap grid library and optimized custom typography theme properties.

## Features
- **About me Section** Minimalist horizontal split card introducing professional credentials as an L1 IT Support Desktop Engineer at CCI Rwanda.
- **Technical Projects Section**  Showcases enterprise support tracks and custom web codebase infrastructure layouts.
- **Education and credential Section** Highlights timeline milestones at St. Joseph Integrated Technical College and any training certifications including the CCI IT Academy and ALX tracks.
- **Connection Hub Section** Aggregates direct contact link pathways such as official email, mobile connectivity, and LinkedIn profile networks.

## How to run this project
This is a client-side static web application. It can be launched locally by opening the entry index file or hosted online using static web servers like GitHub Pages.

### Prerequisites
To read, edit, or execute this codebase locally, you need:
- A modern web browser (e.g., Google Chrome, Mozilla Firefox, Microsoft Edge, or Safari).
- A text or code editor (e.g., VS Code, Notepad++) for content customization.
- Git installed locally if staging adjustments via terminal command interfaces.

### Installation
1. **Clone the repo:**
   ```bash
   git clone https://github.com/Teckla23/MyPortfolio.git
   ```
2. **Navigate into the workspace folder:**
   ```bash
   cd MyPortfolio
   ```
3. **Verify internal project file layout structures:** Ensure that `index.html`, `bootstrap.min.css`, `styles/main.css`, and your asset graphics directory (`images/`) exist within the root workspace environment.
4. **Launch the profile interface layout:** Double-click on `index.html` or right-click to choose **Open with Web Browser** to view the centered responsive web layout presentation card.
